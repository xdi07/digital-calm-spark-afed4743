FocusNest

FocusNest is a modern student productivity application designed to help students stay focused, manage their study time, and build consistent learning habits. It provides a clean, distraction-free environment with tools that improve productivity and encourage effective time management.

---

Features

- Focus Timer based on the Pomodoro technique
- Study progress tracking and analytics
- Daily study goals and streak monitoring
- Organized study sessions
- Responsive and user-friendly interface
- Clean and modern design

---

Technologies Used

This project is built using:

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

---

Installation

Prerequisites

Before running the project, ensure you have the following installed:

- Node.js
- npm

Clone the Repository

git clone https://github.com/xdi07/FocusNest.git

Navigate to the Project Directory

cd FocusNest

Install Dependencies

npm install

Start the Development Server

npm run dev

The application will start locally, and you can access it in your browser.
